# Notes on this chapter

1. Variables contain nonsense values when uninitialised

2. printf uses the following to print values:
    %d = int
    %f = float
    %s = string

3. C traditionally didn't have booleans, 0 = False, anything else = True. Best practice kept as 1 and 0. C23 has booleans though! Or import via <stdbool.h> but they boil down to 1 and 0 too

4. C has terinaries!

5. Post-increment does the expression first, THEN does the increment. Pre-increment does the increment first THEN the expression.
